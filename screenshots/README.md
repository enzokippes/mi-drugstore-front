## How to Capture

1. **Store screenshot**: Open `http://localhost:5173` in your browser and capture the main store view
2. **Admin dashboard**: Log in as admin, go to `/dashboard` and capture the statistics view
3. **Mobile screenshot**: Open DevTools, set viewport to iPhone 14 Pro (390x844), and capture the store
4. **Points screenshot**: Log in as a user with points, go to `/points` and capture
5. **Profile screenshot**: Log in, go to `/profile`, add an address if needed, and capture

## Guidelines

- Use PNG format for all screenshots
- Name files exactly as shown above (lowercase with hyphens)
- Try to capture without browser extensions or developer tools visible
- For mobile screenshots, show the hamburger menu open if possible
